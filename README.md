# AI WhatsApp Sales CRM

A premium, state-of-the-art WhatsApp CRM designed for high-performance sales teams. This platform integrates AI-driven insights, automated workflows, and comprehensive lead tracking to streamline your WhatsApp sales engine.

## ✨ Features

- **📊 Modern Dashboard**: Real-time KPIs, revenue tracking, and sales analytics.
- **📥 Unified Inbox**: Manage WhatsApp conversations with tags, notes, and quick replies.
- **🎯 Lead Management**: Advanced tracking for hot, warm, and cold leads with detailed profiles.
- **🚀 Sales Pipeline**: Kanban-style deal tracker to visualize your sales funnel.
- **📣 Smart Campaigns**: Send bulk WhatsApp broadcasts with WABA-approved templates.
- **🤖 AI Auto-Pilot**: Automate responses, assign agents, and analyze customer sentiment.
- **📈 Global Insights**: Pie charts and bar graphs for lead sources and conversion funnels.
- **🔒 Secure Console**: Manage team roles, billing, and API integrations.

## 🛠 Tech Stack

- **Framework**: [Next.js 15+](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Components**: [Base UI](https://base-ui.com/), [Lucide React](https://lucide.dev/)
- **Charts**: [Recharts](https://recharts.org/)
- **Fonts**: [Geist](https://vercel.com/font)
- **State/Types**: TypeScript

## 🚀 Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 📖 Project Structure

- `src/app/(dashboard)`: Main application pages (Dashboard, Leads, Pipeline, etc.)
- `src/app/auth`: Login and Signup pages.
- `src/components/ui`: Highly customizable UI components.
- `src/components/layout`: Global navigation and sidebar components.
- `public/`: Static assets (avatars, icons).
